# fclementic2c.github.io

Héberge la clé publique de mon application Tesla Fleet API (pilotage local de la recharge solaire avec evcc) :

`/.well-known/appspecific/com.tesla.3p.public-key.pem`

Ne pas supprimer ni modifier ce fichier : Tesla l'utilise pour authentifier les commandes envoyées à la voiture.
